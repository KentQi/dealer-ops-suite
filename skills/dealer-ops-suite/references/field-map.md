# 字段清单（标准版）

本清单是 `scripts/spec/*.json` 的人读版本，两者必须一致；改字段时先改 JSON，再同步本表。

- **JX** = 经销合同（`1-经销/`）
- **DX** = 铺货代销合同（`2-铺货代销/`），与 JX 同源的商务条款，另加铺货专属三项
- **FC** = 附件一《线下经销商防窜货管理规定》

「示例」列同时给出模板默认值。凡标 **默认** 的，模板已有值，用户不回就保持原样。

### 锁定内容（不填、不改）

附件一的违约金标准表属标准条款，除非用户明确要求调整，否则原样保留；
在 `spec.locked_content` 登记了标准表时，`scan_blanks.py`（模板扫描）与
`verify_fill.py`（收尾验收）都会把实际表内容与标准版逐格比对，不一致即报警 /
判越界。公开脱敏版未登记标准表（验收单会显式标注「未登记，本次未校验」），
接入真实附件一时按 `docs/SANITIZATION.md` 补登数据即自动恢复比对：

- 线上窜货：按合同约定的阶梯处理，累计次数达到约定上限可解除合同
- 线下窜货：按合同约定的货值倍数处理
