# 公开版脱敏说明

这个仓库是从内部工作版整理出的**公开脱敏版**。目标是保留完整工作流与代码结构，同时不暴露任何真实客户、合同、价格或账户信息。

| 类别 | 处理 |

| 经销商名称 | 替换为「示例经销商有限公司」 |
| 统一社会信用代码 | 替换为校验位合法的虚构代码：`91310000MA1FL0000N`、`91440100MA5C000005`、`91330100MA2C00000P` |

## 使用提醒

这是**模板**，不是可直接用于真实业务的成品。接入真实合同与客户数据前，请先替换 `scripts/spec/*.json`、`assets/*` 与 `references/field-map.md` 中的示例值，并在私有仓库中保存真实数据。
